# Assets

> Visual assets for the ToneCraft design system.
> This folder contains icons, illustrations, and reference images.

## Structure

```
Assets/
├── icons/           # Custom icon SVGs
├── illustrations/   # Empty state illustrations
├── logos/           # Brand logo variants
├── gradients/       # Gradient presets and references
├── textures/        # Noise grain and surface textures
└── references/      # Color swatches, typography samples
```

## Asset Guidelines
- All icons use lucide-react as the base library
- Custom icons are SVG with consistent stroke weight (1.5px)
- Illustrations are minimal, editorial line style
- Logos are never distorted or placed on busy backgrounds
- Gradients use the tone-specific color mappings from the Design System
- Textures are subtle (1-2% opacity noise grain)
