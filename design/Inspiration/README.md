# Inspiration Board

> Collect screenshots of reference products for design inspiration.
> Do not copy — study spacing, typography, motion, icon sizes, shadows, empty states, onboarding, gradients, and AI interactions.

## Collection Guidelines
- Capture at native resolution
- Organize by category (spacing, typography, motion, etc.)
- Annotate what you learned from each screenshot
- Focus on what makes each product unique, not what is generic
