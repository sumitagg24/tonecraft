# ToneCraft v1.0.0-beta — Release Notes

> Tag: `v1.0.0-beta` · Branch: `phase-8-product-architecture` · Date: 2026-08-02
> This release captures **Phases 5–8** — from the first production-grade landing page to a
> feature-complete, security-hardened AI writing workspace.

---

## What's in this release

### Product features (Phase 8)

- **Projects** — organize chats into projects with a sidebar tree and project pages (`/p/[projectId]`).
- **Prompt library** — CRUD prompts with variables, template rendering, favorites, recents, and bulk import/export (up to 500 at once).
- **Personas** — curated presets + custom personas with favorites, defaults, and persona-aware generation (system prompt, tone, writing style, emoji usage).
- **Knowledge base** — upload documents (PDF/TXT/MD/HTML/JSON/XML/CSV) with text extraction, chunking, retrieval, and **grounded answers with inline citations** `[1]`, `[2]`.
- **Search** — one box across chats, messages, prompts, personas, and knowledge files.
- **Export & share** — export any chat to Markdown, TXT, HTML, or JSON, with shareable read-only links.
- **Notifications** — in-app bell + notifications page + real-time SSE stream; preference toggles in settings; events for exports, knowledge indexing, credits, invites, comments.
- **Offline & drafts** — offline detection + sync bar, outbox sync, draft tray with auto-save and restore.
- **Comments & analytics** — thread comments on chats, and an analytics page (`/api/analytics/me`, `/admin`) built on usage data.

### AI engine (Phase 8.15)

- Single source of truth for models via `ModelRegistry`; retired models removed.
- Idle-based streaming timeout + client-disconnect chaining (aborting a chat cancels the upstream call).
- Typed tool protocol (`AITool` + `ToolRegistry`) as the onboarding point for MCP/agents.
- Failover retries 5xx/network errors across providers.

### Platform & engineering (Phases 5–7 + 8.12–8.14)

- **Phase 6:** full backend architecture — provider abstraction, credits/usage system, Paddle billing (checkout, portal, verified webhooks), Clerk auth.
- **Phase 7:** complete UI overhaul — Design System 2.0 (tokens for color, type, motion, elevation, radius), navigation shell (rail + sidebar + top bar), rebuilt landing page, true streaming chat UX with real abort, tone system, integrated tool picker, mobile polish with bottom sheets, micro-interactions.
- **Phase 8.12:** one standardized API envelope (`{success, data}` / `{success, error}`) via a shared `withApiHandler` (auth + zod validation + try/catch + requestId + logging) across every route.
- **Phase 8.13:** streaming-path performance — zustand selectors, memoized lists, rAF-coalesced scroll, tree-shakeable icons, ~250 fewer lines and 3 dead dependencies removed.
- **Phase 8.14:** database optimization — redundant indexes removed, `Message.parentId` index, pgvector + retention migrations prepared.

### Reliability, security & production-readiness (Phase 8.17)

- **Security:** message IDOR closed (ownership-scoped mutations), Paddle webhook unblocked, magic-byte upload validation with plan caps, rate limits on every LLM-costly path, production CSP + security headers, `poweredByHeader` off.
- **Ops:** env fail-fast at boot, fail-closed rate limiting, error-reporting abstraction (Sentry-ready), sanitized `/api/health`, `robots.txt` + `sitemap.xml`, backup & DR runbook.
- **UX consistency (8.16):** shared Radix `Modal`, unified empty/loading states, font-size tokens, `role="status"` accessibility.

### Documentation

12 audits, 10 product specs, 6 research docs, 10 ADRs, migration reports 8.12–8.17, a backup runbook, and this release's four closing reports
(`docs/reports/phase-8-final-report.md`, `product-readiness-report.md`, `launch-checklist.md`, `technical-debt-register.md`).

## Known issues & limitations

- **No automated tests yet** — manual smoke only (audit 11 strategy written; Milestone 1 is next).
- **No CI/CD pipeline** — `lint` is the only wired check.
- **Sentry ready but not active** — set `SENTRY_DSN` to turn on error reporting.
- **Rate limiting fails closed in production** without Upstash env vars — set them.
- **Synchronous jobs** — knowledge indexing and exports run in the request path (queue deferred).
- **Offline is partial** — drafts/outbox sync exist; no offline PWA yet.
- **Share links** are currently account-gated pending a policy decision.
- **Anthropic** is config-ready but has no client; provider routing uses Groq/Google/OpenRouter (user-keyed).

## Deferred to 1.1+

pgvector embeddings, retention job execution, daily upload buckets, internal provider-health dashboard, AI observability, dead-code cleanup (audit 01), structured request logging.
