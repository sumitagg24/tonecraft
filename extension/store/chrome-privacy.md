# Store privacy summary (must match docs/extension-privacy.md)

- **Data collected only on user action:** selected/composed text (≤8000
  chars), chosen tool and options, login credential for our own API.
- **Never collected:** keystrokes, full page contents, passwords, payment
  data, browsing history.
- **Purpose:** provide the requested rewrite/generation via the user's
  ToneCraft account (server-side AI under the website's privacy policy).
- **Sharing:** no sale, no advertising, no third-party SDKs. Text is
  processed by ToneCraft's backend/AI providers per the website policy.
- **Storage:** settings on device; session token in memory only (cleared on
  browser close); server data under the website retention policy.
- **User control:** uninstall removes on-device data; website sign-out
  invalidates the session.

Full text: docs/extension-privacy.md in the repository.
