## Step-by-Step

### Step 1: Export Dialog

**Trigger:** Click "Export" button in ChatHeader (next to Share)

**Dialog layout:**
```
┌─────────────────────────────────────────┐
│ Export Chat                             │
│ ─────────────────────────────────────── │
│                                         │
│ Format:                                 │
│  (●) Markdown                           │
│  (○) PDF                                │
│  (○) JSON                               │
│  (○) Plain Text                         │
│                                         │
│ Options:                                │
│  [x] Include metadata                   │
│  [x] Include timestamps                 │
│  [ ] Include AI reasoning               │
│                                         │
│ ─────────────────────────────────────── │
│ [Cancel]         [Export]               │
└─────────────────────────────────────────┘
```

**Format options:**
- **Markdown**: `.md` — preserves formatting, best quality
- **PDF**: `.pdf` — print-ready, includes styling
- **JSON**: `.json` — raw data, structured
- **Plain Text**: `.txt` — stripped formatting

**Options:**
- Include metadata (tone used, model, timestamp, tokens)
- Include timestamps (per-message)
- Include AI reasoning (thinking steps, if available)

---

### Step 2: Export Generation

**On click "Export":**
1. Button shows spinner: "Exporting..."
2. `POST /api/chats/{chatId}/export` with format + options
3. Server generates file
4. Progress: spinner overlay (no progress bar for short exports)

**Async export (large chats):**
- If chat > 100 messages, server queues export
- `POST /api/exports` → returns `{ exportId }`
- Email notification when ready
- Download link in app

---

### Step 3: File Delivery

**Immediate download (small chats):**
- Server returns file as Blob
- Browser triggers download via `a[download]`
- Filename: `{chat-title}-{date}.md`

**Queued download (large chats):**
- Toast: "Export started. You'll get a download link when ready."
- User can check `/exports` for status
- Email sent on completion

## Share Flow (Alternative)

**Trigger:** Click "Share" in ChatHeader

**Options:**
1. **Copy link** — copies `/chat/{chatId}` to clipboard
2. **Twitter** — opens tweet composer with link
3. **LinkedIn** — opens share dialog with link
4. **Invite...** — opens email invite form

**Behavior:**
- Shared links are view-only by default
- Recipient can sign in to comment
- Link can be revoked from Share dialog
- Optional password protection (future)

---

## Error Handling

| Scenario | Handling |
|----------|----------|
| Export API failure | Toast: "Export failed" with retry option |
| Large file timeout | Toast: "Export queued, check email" |
| Unsupported format | Toast: "That format isn't available" |
| Network error | Toast: "Network error, try again" |

## Export Data Structure

**Markdown format includes:**
```markdown
# {Chat Title}

*Exported: {timestamp}*
*Tone: {tone}* · *Model: {model}* · *Tokens: {count}*

---

**[User]** *{time}*
{message content}

**[AI]** *{time}*
{message content}
{reasoning (if enabled)}

---

*Generated by ToneCraft*
```

**JSON format:**
```json
{
  "chatId": "...",
  "title": "...",
  "metadata": { "tone": "...", "model": "...", "tokens": ... },
  "messages": [
    { "role": "user", "content": "...", "timestamp": "...", "tokens": ... },
    { "role": "assistant", "content": "...", "timestamp": "...", "tokens": ... }
  ]
}
```
